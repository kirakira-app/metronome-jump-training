メトロノーム・ジャンプ・トレーニング（ログイン不要版）

【内容】
・Firebase認証／Firestore／ログイン機能を削除
・キャラクター画像と背景画像は元の画像を初期表示
・右上の歯車から画像を任意に変更可能
・変更画像はこの端末のブラウザ（IndexedDB）に保存
・初期画像に戻す機能あり
・カメラ、メトロノーム、BPM変更、ジャンプ回数、Gemini AIアドバイスは維持

【GitHub Pagesへの反映】
ZIPを展開し、index.html と assets フォルダをリポジトリのルートにアップロードして置き換えてください。
既存の index.html は先にバックアップしてください。

【注意】
画像の変更は端末ごとです。別端末には同期されません。Gemini AIアドバイスを使う場合はAPIキーが必要です。
